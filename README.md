Python 3.10 이상을 사용한 콘솔 기반 퀴즈게임

* 메뉴
* 종료 기능 \[o]
* 선택 기능 \[o]
* 오입력 처리 \[o]
* 퀴즈 풀기 \[o]
* 퀴즈 출제 \[o]
* 정답 입력 \[o]
* 정/오답 여부 출력 \[o]
* 결과 출력 \[o]
* 예외사항 처리 \[o]
* 퀴즈 추가 \[o]
* 필요한 정보 : 문제, 선택지(4개), 정답 번호 \[o]
* 오입력 처리 \[o]
* 추가 퀴즈 저장 \[o]
* 퀴즈 목록 확인 \[o]
* 저장 퀴즈 목록 확인 \[o]
* 예외사항 처리 \[o]
* 점수 확인 \[o]
* 최고 점수 확인 \[o]
* 퀴즈 종료 시 최고 점수와 비교 및 갱신 \[o]
* 최고 점수 저장 \[o]
* JSON 파일을 통한 데이터 저장 \[o]
